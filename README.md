# discord-botu-islemci-ram-sistem-islemci


# 🤖 Discord Sistem Bilgileri Botu

Python ve `psutil` kullanılarak geliştirilmiş basit bir **Discord sistem bilgi botu**.

## ✨ Özellikler

* 🖥️ CPU kullanımını ölçer
* 🧠 RAM kullanımını gösterir
* 📊 CPU ve RAM bilgilerini birlikte gösterir
* ⏱️ CPU kullanımını 10 saniye boyunca ölçebilir

## 📌 Komutlar

| Komut      | Açıklama                        |
| ---------- | ------------------------------- |
| `!islemci` | CPU kullanımını 10 saniye ölçer |
| `!ram`     | RAM kullanımını gösterir        |
| `!sistem`  | CPU ve RAM kullanımını gösterir |

## 🛠️ Kullanılan Teknolojiler

* 🐍 Python
* 🤖 Discord.py
* 💻 Psutil

## 📦 Kurulum

Gerekli kütüphaneleri yükleyin:

```bash
pip install discord.py psutil
```

Daha sonra bot tokenınızı kodun en altında kullanın:

```python
bot.run("BOT_TOKEN")
```

> ⚠️ Bot tokenınızı GitHub'a yüklemeyin. Tokenınızı gizli tutun.
